❓ Cómo jugar

  • 🕹️ En el teléfono: mueve el joystick izquierdo para correr y toca SALTAR para brincar.
  • ⌨️ En la computadora: usa WASD o las flechas para moverte y ESPACIO para saltar.
  • 🪙 Recoge monedas: ¡sirven para comprar sombreros y estelas!
  • 🚩 Toca las banderas para guardar tu punto de control.
  • ⚠️ Cuidado con las barras giratorias, los pisos que desaparecen y la lava.
  • 🟩 Los trampolines verdes te lanzan muy alto.
  • ✈️ Aviones: súbete en la pista brillante para volar. Joystick o WASD para dirigir, SALTAR para turbo, botón BAJAR para salir.
  • 🚗🚲 Carros y bicis: acércate y toca SUBIR (o tecla E) para manejar.
  • 🪂 Ponte el paracaídas en Personalizar: se abre solo si caes desde muy alto.
  • 🌍 Mundo libre: aquí no hay niveles ni metas, explora y quédate el tiempo que quieras.
  • 🪧 Compra tu lote y construye tu casa o negocio.
